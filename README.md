A coined English word and a one-line definition. Written for make.fun's Invent a Word We Need bounty.

## Run it

```sh
python3 -P -s main.py
```

Writes one coined word and its definition (at most 140 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that directory exists, and prints the same text. Locally, if neither is set, it writes `./output/entry.txt`.
